OPEN THE WEBSITE
1. Open this folder in Visual Studio Code.
2. Open index.html in a browser, or use the Live Server extension.
3. Use the navigation menu to visit the other four pages.

FILES
- index.html: Home page
- fragrance-guide.html: Fragrance education page
- recommendations.html: Recommendation cards
- reviews.html: Cologne reviews
- find-your-scent.html: Interactive scent quiz
- css/styles.css: External CSS
- js/script.js: Quiz interaction
- images/fragrance-hero.png: Home page photograph

CSS REQUIREMENTS
- External CSS is in css/styles.css.
- Internal CSS appears in the <style> section of every HTML file.
- Inline CSS appears on the call-to-action elements in index.html and find-your-scent.html.

VALIDATION
All five HTML files and the external CSS file were checked during development.
